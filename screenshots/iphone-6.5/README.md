# iPhone 6.5-inch screenshots

Native, unscaled PNG captures from **iPhone 11 Pro Max**, iOS 26.5,
using Xcode 26.6 on September 19, 2026. Every image is **1242 × 2688** pixels,
portrait, English (US), light appearance. The populated screens use fictional
data; no personal data is included.

| File | Screen |
| --- | --- |
| [01-welcome.png](01-welcome.png) | Create a home profile |
| [02-due.png](02-due.png) | Due and overdue maintenance |
| [03-upcoming.png](03-upcoming.png) | Recurring maintenance schedule |
| [04-completed.png](04-completed.png) | Completion history and notes |
| [05-setup.png](05-setup.png) | Homes, rooms, and assets |
| [06-privacy-data.png](06-privacy-data.png) | Privacy, JSON backup, and restore |

Regenerate with `./scripts/capture-screenshots.sh` from the repository root.
The fixture dates are relative to capture day, so repeated runs retain realistic
upcoming and overdue tasks. Review images after capture for simulator system
banners before uploading to App Store Connect.
