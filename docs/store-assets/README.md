# Store visual assets

The two SVG files in this directory are **layout placeholders**, not screenshots
and not evidence that the app was run on a device. Each is visibly watermarked
`PLACEHOLDER — NOT A PRODUCT SCREENSHOT`.

Replace them with privacy-reviewed captures from the exact release candidate only
after the manual TalkBack/VoiceOver checklist. Keep any retained source capture
outside the repository if it contains personal household data. Store upload sizes
and device classes must be checked against the current Apple/Google requirements
at submission time.

The launcher icon source is `assets/branding/upkeep-log-icon.svg`; committed
Android and iOS PNG renditions contain no transparency in the iOS marketing icon.
