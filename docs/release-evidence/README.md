# Release evidence folder

Store human-produced release evidence that cannot be generated by CI:

- manual TalkBack and VoiceOver runs
- device-specific install/upgrade checks
- owner signing verification notes

Use `docs/accessibility-verification-template.md` as the baseline format for
accessibility runs. Keep evidence files in git with dated filenames (for
example `2026-09-07-accessibility.md`) so draft-to-ready transitions are
reviewable.
